# Speech Synthesize

A Python starter for local text-to-speech with a CLI, optional FastAPI service, tests, and CI. The initial engine uses `pyttsx3` and depends on a compatible system voice engine.

## Requirements
- Python 3.11+
- A platform speech engine supported by `pyttsx3` (for example SAPI5 on Windows or eSpeak on many Linux distributions).

## Install
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -e ".[api,dev]"
```

## CLI
```bash
speech-synthesize --text "Hello world" --output output/hello.wav
speech-synthesize --input samples/hello.txt --output output/hello.wav
speech-synthesize --list-voices
```

## Optional HTTP API
```bash
python -m pip install -e ".[api]"
uvicorn speech_synthesize.api:app --host 127.0.0.1 --port 8000
```
Browse `http://127.0.0.1:8000/docs`. `POST /v1/synthesize` accepts JSON such as `{"text":"Hello from the API"}`. Output paths are generated by the server. Keep this development API on localhost; add authentication, quotas, rate limiting, and retention controls before deployment.

## Project status
This repository was empty at setup time; these files form an initial implementation and should be exercised on each target platform. Audio codec support depends on the installed system voice driver.
